# 摄影作品站

按 Figma 设计稿复刻的静态网站，放在 GitHub Pages 上，免费。网站自带编辑模式：在网页上点字直接改、点照片直接换，改完点一下发布，不用碰代码。

## 第一次：把网站放上 GitHub（只做一次）

1. 登录 GitHub，新建一个公开仓库，名字写 `你的用户名.github.io`。
2. 在新仓库页面点 uploading an existing file，把这个文件夹里的所有文件和文件夹拖进去，点 Commit changes。
3. 打开仓库的 Settings → Pages：Source 选 Deploy from a branch，分支选 `main`，目录选 `/ (root)`，点 Save。
4. 等一两分钟，打开 `https://你的用户名.github.io`，网站就上线了。

## 以后：在网页上直接改

1. 打开 `https://你的用户名.github.io/#edit`（就是网址后面加 `#edit`，建议存成书签）。
2. 页面上有虚线框的文字都能直接点进去改，回车换行；照片右上角点"换照片"，选手机或电脑里的照片就行。
   - 照片会自动压缩到长边 2560px，并去掉照片里的 GPS 定位信息。
   - 名字、城市、导航、页脚这些每页都有的内容，改一处，所有页面一起更新。
   - 社交账号的链接：点那几个字，下面会弹出输入框填网址。邮箱改了，邮件链接会自动跟着改。
3. 点底部的"发布到 GitHub"。第一次会弹出设置窗口，按里面的步骤在 GitHub 生成一个"令牌"粘贴进去（只能改这个仓库，存在你自己的浏览器里）。之后每次直接点发布。
4. 一两分钟后刷新网站就能看到新内容。

要改别的页面：用底部工具栏里的下拉框切换（先发布当前页的修改再切换）。

连不上 GitHub 的时候，可以点"下载修改"，会得到一个压缩包。解压后把里面的文件拖到 GitHub 仓库的上传页面（Add file → Upload files），同名文件会被替换。

说明：别人打开 `#edit` 也只能在自己的浏览器里看看，没有你的令牌就发布不了。不要在公共电脑上勾选"记住"。

## 还要填的内容

网站里写着 `[你的名字]`、`[城市]`、`[你的邮箱]` 和中括号说明的地方，以及所有照片和照片说明（现在都是模板自带的示例），都在编辑模式里直接改掉就行。

## 给需要的时候看：技术说明

- 文件：`index.html` 首页、`work.html` 作品、`about.html` 关于、`journal.html` 手记、`contact.html` 联系；样式在 `assets/css/style.css`（颜色、字体、间距都在开头的 `:root` 变量里）；编辑器在 `assets/js/editor.js` 和 `assets/css/editor.css`，只有网址带 `#edit` 时才加载。
- 元素编号：网址后面加 `#ids`，会标出 H1、A1、F3 这样的编号（H 页眉，F 页脚，A 首页，B 作品，C 关于，D 手记，E 联系），找 Claude 改设计时可以直接说编号。
- 本地预览：在这个文件夹里运行 `python -m http.server`，打开 http://localhost:8000 。
- 字体：Instrument Serif 和 Inter，都是 SIL OFL 开源授权，已打包在 `assets/fonts/`，不依赖 Google Fonts。

## 相对 Figma 设计稿的改动

1. 个人信息换成占位，版权年份改为 2026。
2. 删除了关于页的推荐语和品牌墙（Kinfolk、Cereal 等）：这些是模板虚构的合作背书。有真实的推荐语或合作再加回来。
3. 统一页眉分隔线；删除作品页标题上方多出来的一条线；修正联系页 "Let’s talk" 看不见的白色箭头。
4. 补了平板和手机布局（设计稿只有 1440 桌面版）。
5. 加了编辑模式、元素编号、悬停效果、键盘焦点样式。
